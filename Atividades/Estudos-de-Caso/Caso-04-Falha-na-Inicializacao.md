# Estudo de caso 04 — Falha na inicialização

## Situação

Após uma atualização de hardware, um computador não inicia o sistema operacional e apresenta uma mensagem relacionada ao dispositivo de boot.

## Análise

O processo de inicialização envolve firmware, verificação do hardware e localização de um dispositivo inicializável. Configuração incorreta de boot ou problemas no disco podem impedir a inicialização.

## Perguntas

1. Qual é a função do BIOS/UEFI?
2. O que é a ordem de boot?
3. Por que o sistema precisa de drivers?
4. Quais verificações iniciais podem ser feitas sem formatar o disco?

## Minha resposta

> Registre possíveis causas e verificações com cuidado para não apagar dados.
