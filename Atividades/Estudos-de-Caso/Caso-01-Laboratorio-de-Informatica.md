# Estudo de caso 01 — Laboratório de informática

## Situação

Um laboratório possui vinte computadores. Alguns alunos utilizam Windows, outros precisam testar Linux para uma atividade. A equipe quer evitar formatar as máquinas toda vez que uma distribuição diferente for estudada.

## Análise

Uma alternativa é utilizar máquinas virtuais, desde que os computadores tenham recursos suficientes. Assim, cada aluno pode criar um ambiente convidado e realizar testes sem substituir o sistema principal.

## Perguntas

1. Qual recurso de virtualização poderia ser utilizado?
2. Quais recursos físicos devem ser verificados antes de criar as VMs?
3. Qual a diferença entre o sistema host e o sistema guest?
4. Cite um cuidado para evitar perda de dados.
