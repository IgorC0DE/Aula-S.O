# Estudo de caso 02 — Computador lento

## Situação

Um computador fica lento quando o usuário abre navegador com muitas abas, editor de texto e videoconferência. O Gerenciador de Tarefas mostra uso elevado de memória.

## Análise

O sistema operacional precisa distribuir a memória entre os processos. Quando a RAM fica pressionada, pode recorrer à memória virtual e ao armazenamento, o que pode reduzir o desempenho.

## Perguntas

1. Qual recurso está sendo muito utilizado?
2. Como identificar quais processos consomem mais memória?
3. O que é memória virtual?
4. Por que utilizar swap não é igual a adicionar RAM?
