# Estudo de caso 07 — Publicação de uma aplicação

## Situação

Um estudante desenvolveu uma aplicação web localmente e deseja disponibilizá-la para que outras pessoas possam acessar pela internet.

## Análise

O processo de deploy envolve preparar o ambiente, instalar dependências, configurar a porta e variáveis de ambiente, publicar a aplicação e verificar se o serviço está funcionando.

## Perguntas

1. O que é deploy?
2. Qual a diferença entre IaaS, PaaS e SaaS?
3. Por que uma aplicação deve utilizar a porta fornecida pelo ambiente de hospedagem quando necessário?
4. Quais informações não devem ser publicadas no repositório?
