# Estudo de caso 05 — Escolha de uma distribuição Linux

## Situação

Uma escola possui computadores antigos e deseja instalar Linux para atividades de navegação, edição de textos e programação básica.

## Análise

A escolha deve considerar requisitos de hardware, facilidade de uso, suporte, atualizações e disponibilidade de programas. Uma distribuição com ambiente gráfico leve pode ser interessante para computadores com recursos limitados.

## Perguntas

1. Quais critérios devem ser avaliados antes de escolher a distribuição?
2. Por que é útil testar uma ISO em máquina virtual?
3. O que significa dizer que uma distribuição é baseada no Ubuntu?
4. Qual distribuição você indicaria e por quê?
