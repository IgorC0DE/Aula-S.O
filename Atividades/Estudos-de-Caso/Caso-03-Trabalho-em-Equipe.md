# Estudo de caso 03 — Trabalho em equipe com Git

## Situação

Dois estudantes estão editando o mesmo projeto. Um altera o README enquanto o outro atualiza um arquivo de código. Eles precisam manter o histórico e compartilhar as alterações.

## Análise

O Git permite registrar alterações em commits. O repositório remoto permite compartilhar o histórico. Branches ajudam a desenvolver mudanças separadamente e integrar o trabalho depois.

## Perguntas

1. Por que cada integrante deve criar commits claros?
2. Para que serve uma branch?
3. Qual a função do push?
4. O que pode causar um conflito de merge?

> Explique como a equipe poderia organizar o trabalho.
