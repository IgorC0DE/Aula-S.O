# Roteiro de testes — Monitor de Sistemas Operacionais

Este roteiro ajuda a testar o projeto Monitor de SO e registrar o que aconteceu durante a execução. Preencha os campos depois de realizar cada teste no seu computador. Não coloque valores estimados como se fossem resultados medidos.

## 1. Preparação

- [ ] Verificar se o Node.js está instalado com `node -v`.
- [ ] Abrir o terminal na pasta `Atividade7-Monitor-SO`.
- [ ] Instalar as dependências com `npm install`.
- [ ] Iniciar a aplicação com `npm start`.
- [ ] Abrir `http://localhost:3000` no navegador.
