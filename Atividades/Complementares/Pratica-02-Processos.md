# Prática 02 — Observando processos

## Objetivo
Identificar programas em execução e entender que cada processo utiliza recursos do sistema.

## Procedimento

No Linux, abra o terminal e utilize:

```bash
ps aux
top
```

No Windows, abra o Prompt de Comando:

```bat
tasklist
```

Também é possível utilizar o Gerenciador de Tarefas para observar CPU e memória.

## Questões

1. Programa e processo significam a mesma coisa?
2. Por que um navegador pode aparecer em mais de um processo?
3. O que pode acontecer se muitos processos exigirem CPU ao mesmo tempo?

*Não encerre processos do sistema sem saber sua função.*
