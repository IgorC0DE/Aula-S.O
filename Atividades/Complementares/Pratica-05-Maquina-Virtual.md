# Prática 05 — Planejando uma máquina virtual

## Objetivo
Planejar a criação de uma máquina virtual para testar uma distribuição Linux.

## Procedimento

1. Escolha uma distribuição Linux para laboratório.
2. Consulte os requisitos recomendados no site oficial.
3. Abra o VirtualBox e inicie a criação de uma máquina virtual.
4. Defina nome, tipo de sistema, memória e disco virtual.
5. Antes de iniciar a instalação, confira as configurações.
