# Prática 06 — Observando o uso de memória

## Objetivo
Consultar a memória utilizada e disponível no sistema.

## Procedimento

No Linux:

```bash
free -h
```

No Windows, abra o Gerenciador de Tarefas, acesse a aba Desempenho e selecione Memória.

## Questões

1. Por que a memória RAM é volátil?
2. O que significa memória disponível?
3. Como o uso de muitos programas pode afetar a memória?
