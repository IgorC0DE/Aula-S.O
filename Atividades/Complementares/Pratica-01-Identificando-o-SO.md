# Prática 01 — Identificando o sistema operacional

## Objetivo
Observar informações básicas do sistema operacional instalado no computador.

## Procedimento

### Linux
Abra o terminal e execute:

```bash
uname -a
cat /etc/os-release
hostname
```

### Windows
Abra o Prompt de Comando e execute:

```bat
systeminfo
hostname
ver
```
