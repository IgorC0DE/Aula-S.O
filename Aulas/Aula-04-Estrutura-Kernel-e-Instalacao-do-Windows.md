# Aula 04 — Estrutura do Sistema Operacional, Kernel e Windows

## Estrutura de um sistema operacional

O sistema operacional é formado por partes que trabalham juntas para controlar o computador. De forma simplificada, podemos pensar na seguinte organização:

1. **Hardware:** parte física do computador, como CPU, memória, disco e periféricos.
2. **Kernel:** núcleo do sistema operacional, responsável por controlar recursos importantes.
3. **Serviços e drivers:** ajudam o sistema a gerenciar funções e conversar com os dispositivos.
4. **Interface e aplicações:** permitem a interação do usuário e a execução dos programas.

## O que é Kernel?

O kernel é a parte central do sistema operacional. Ele faz a ligação entre os programas e o hardware e controla recursos essenciais.

Entre suas responsabilidades estão:

- Gerenciar processos e escalonar o uso da CPU.
- Controlar a memória.
- Gerenciar dispositivos por meio de drivers.
- Oferecer mecanismos para os programas solicitarem serviços do sistema.

O kernel não é a mesma coisa que a interface gráfica. Mesmo sem uma área de trabalho visual, o sistema pode continuar funcionando por meio de um terminal.

## Instalação e formatação do Windows

A instalação de um sistema operacional prepara o computador para utilizar o ambiente. Em uma instalação limpa do Windows, normalmente são necessárias etapas como:

1. Verificar os requisitos mínimos do sistema.
2. Fazer backup dos arquivos importantes.
3. Preparar uma mídia de instalação.
4. Iniciar o computador pela mídia.
5. Escolher idioma e configurações.
6. Selecionar o disco ou a partição de destino.
7. Aguardar a instalação e realizar a configuração inicial.

**Atenção:** formatar ou excluir partições pode apagar os dados. É importante conferir o disco selecionado e ter cópia dos arquivos antes de começar.

## Sistemas derivados

Um sistema derivado é construído a partir de outro sistema ou projeto, aproveitando parte de sua estrutura e modificando ou acrescentando recursos. No mundo Linux, por exemplo, existem distribuições baseadas em outras distribuições.

## O que ficou da aula

O kernel é essencial para o funcionamento do sistema operacional, pois gerencia a comunicação com o hardware. Também é importante entender que instalar e formatar um sistema exige cuidado com os dados armazenados.
