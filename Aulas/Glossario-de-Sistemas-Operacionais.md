# Glossário básico — Sistemas Operacionais

Este glossário reúne termos que aparecem nas aulas e atividades. As definições são resumidas para facilitar a revisão.

| Termo | Definição |
|---|---|
| BIOS/UEFI | Firmware responsável por inicializar e configurar o hardware antes de carregar o sistema operacional. |
| Boot | Processo de inicialização do computador e carregamento do sistema operacional. |
| Batch | Processamento em lote de tarefas, sem interação constante durante a execução. |
| Branch | Linha independente de desenvolvimento em um repositório Git. |
| Container | Ambiente isolado para executar uma aplicação e suas dependências, normalmente compartilhando o kernel do host. |
| CPU | Unidade central de processamento que executa instruções. |
| Deploy | Processo de disponibilizar uma aplicação em um ambiente de execução. |
| Driver | Software que permite ao sistema operacional controlar ou se comunicar com um dispositivo. |
| Guest | Sistema operacional executado dentro de uma máquina virtual. |
| Host | Computador físico que hospeda uma máquina virtual ou container. |
| Hypervisor | Camada de software que cria e gerencia máquinas virtuais. |
| Kernel | Núcleo do sistema operacional, responsável por gerenciar recursos e oferecer serviços aos programas. |
| Memória RAM | Memória volátil utilizada para armazenar temporariamente dados e instruções em uso. |
| Memória virtual | Técnica que oferece aos processos um espaço de endereçamento virtual e permite mapear páginas para a memória física. |
| Multiprogramação | Técnica que mantém vários programas disponíveis para melhorar a utilização da CPU. |
| Paginação | Técnica que divide o espaço de memória em páginas e quadros de tamanho fixo. |
| Processo | Instância de um programa em execução, com estado e recursos próprios. |
| Sistema de arquivos | Estrutura e conjunto de regras usados para organizar arquivos e diretórios. |
| Swap | Área de armazenamento utilizada como apoio à memória principal. |
| VM | Máquina virtual que simula um computador e executa um sistema convidado. |

## Como utilizar

Ao encontrar um termo desconhecido em uma aula, consulte o glossário e depois volte ao material original para ver o conceito em contexto. As definições são introdutórias e podem ser aprofundadas nas referências da disciplina.
