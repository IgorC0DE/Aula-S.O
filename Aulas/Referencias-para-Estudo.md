# Referências para estudo — Sistemas Operacionais

As páginas abaixo são fontes oficiais ou documentação técnica para aprofundar os assuntos estudados. Consulte a documentação correspondente à versão do software utilizada.

## Sistemas operacionais e kernel

- [The Linux Kernel Archives](https://www.kernel.org/) — código-fonte, versões e informações do kernel Linux.
- [Linux Kernel Documentation](https://docs.kernel.org/) — documentação técnica do kernel.
- [Microsoft Learn — Windows](https://learn.microsoft.com/windows/) — documentação do Windows.
- [Apple Open Source](https://opensource.apple.com/) — projetos de código aberto da Apple, incluindo componentes relacionados ao XNU.

## Virtualização e Linux

- [Oracle VM VirtualBox](https://www.virtualbox.org/) — página oficial e documentação do VirtualBox.
- [Ubuntu](https://ubuntu.com/) — informações e documentação da distribuição Ubuntu.
- [Debian](https://www.debian.org/) — informações oficiais do projeto Debian.
- [Fedora Docs](https://docs.fedoraproject.org/) — documentação do Fedora.

## Containers e nuvem

- [Docker Documentation](https://docs.docker.com/) — conceitos e instruções para utilizar Docker.
- [NIST — The NIST Definition of Cloud Computing](https://csrc.nist.gov/pubs/sp/800/145/final) — definição e características da computação em nuvem.
- [Kubernetes Documentation](https://kubernetes.io/docs/home/) — documentação sobre orquestração de containers.

## Git e GitHub

- [Git Documentation](https://git-scm.com/doc) — documentação oficial do Git.
- [GitHub Docs](https://docs.github.com/) — guias sobre repositórios, commits, branches e colaboração.

## Livro de apoio

- TANENBAUM, Andrew S.; BOS, Herbert. *Sistemas Operacionais Modernos*. 4. ed. Pearson, 2016.

> Os links foram reunidos como ponto de partida para consulta. Ao utilizar uma informação específica em um trabalho, registre a fonte e a data de acesso conforme a orientação do professor.
